# Portfolio

A minimal, bold, black & white portfolio built with Vite + React + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build for production

```bash
npm run build
```

Output goes to the `dist/` folder — deploy it anywhere (Vercel, Netlify, GitHub Pages, etc).

## Customize

All content lives in `src/App.jsx`:
- `projects` array — swap in your real projects, years, and tags
- `skills` array — your actual stack
- Name, bio, email, and social links are inline in the JSX — search for "Jordan Cole" and `jordan.cole@example.com`

Colors and fonts are defined in `tailwind.config.js` (`ink`, `paper`, `muted`) if you want to adjust the palette later.
